# 日常有迹

由「饭饭签」改版的个人饮食、体重与运动记录工具。

公开网址：https://luckytoday789.github.io/The-eating-project/

## 使用

- 选择日期，记录早餐、午餐、晚餐和加餐，可填写内容、分量与时间。
- 每天记录一个体重（kg），支持修改或删除。
- 记录运动类型、时长、主观强度、可选距离和备注。
- 在日历中补记或回看，在趋势页查看最近 7 / 30 / 90 天的数据。
- 数据保存在当前浏览器 localStorage 中，不上传到服务器；不同设备不会自动同步。
- 使用「数据与备份」导出 JSON，在另一台设备中导入合并。清理浏览器数据前请备份。
- 示例模式的数据只在内存中存在，不写入个人记录。

## 开发与发布

原生 HTML / CSS / JavaScript，无安装和构建步骤。使用任意静态 HTTP 服务预览本目录。

`core.js` 包含数据校验、合并与统计逻辑。执行 `node tests/core.test.cjs` 进行检查。

`main` 保存源文件，`gh-pages` 为 GitHub Pages 的发布分支。发布时同步两个分支，等待 Pages 构建成功。

## 数据合并规则

- 新日期整天导入。
- 饮食、运动按同日记录 ID 合并，重复 ID 取更新时间较新的条目。
- 当天已有体重和备注优先保留，备份只补空值。
- 不支持的版本、无效日期、不合法数值和超限内容会阻止导入，不会覆盖现有数据。
