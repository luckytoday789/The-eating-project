# 日常有迹 · 安卓版

这是独立安装的离线应用，用来记录每天的饮食、体重、运动和备注。无需运行电脑，也无需打开原来的网页。

## 安装与使用

1. 将 `release/日常有迹-1.1.0.apk` 通过微信、QQ 的文件发送功能或数据线传到安卓手机。
2. 在手机的文件管理器中打开 APK，按系统提示允许此次安装。若聊天软件无法直接打开，先保存到手机，再从文件管理器打开。
3. 安装后点击桌面上的「日常有迹」即可使用。

支持 Android 8.0 及以上，手机的 Android System WebView 或 Chrome 需为 107 及以上版本。若打开时提示更新网页组件，先更新系统组件再重试。APK 不能安装在 iPhone 上。

点击有轻触反馈，日期条支持左右滑动，切换页面有轻翻页效果。在「数据与备份 → 使用手感」中可关闭页面动效和点击触感；应用遵循系统的触感与减少动态效果设置。

## 从网页版迁移记录

1. 在原来使用的浏览器中打开网页版，进入「数据与备份」，导出 JSON 备份。
2. 将 JSON 文件传到手机。
3. 打开安卓应用的「数据与备份」，选择 JSON 备份并确认合并。

重复导入会按记录编号合并；同一天本机已有的体重和备注会保留。导入前可先导出一份当前手机记录，方便核对。

## 记录与备份

- 记录只保存在当前手机。网页版、其他手机和安卓应用之间不会自动同步。
- 卸载应用、清除应用数据或更换手机前，请先导出 JSON 备份，并将备份存到应用以外的位置。
- 应用另存有本机恢复快照，用于网页存储异常时尝试恢复；快照也会随卸载或清除数据而删除，不能代替导出备份。
- 本版不申请网络、广泛存储访问或振动权限。导入导出使用系统文件选择器，触感使用系统界面反馈。

## 源码与构建

- 本地 `daily-journal/`（GitHub 仓库根目录）：界面、交互与记录逻辑。构建脚本兼容两种布局。
- `android/`：安卓容器，包名 `cn.dailytraces.journal`。
- `scripts/build-android.ps1`：构建和签名脚本，使用 `E:\HH\tools` 中现有的 JDK、Gradle 和 Android SDK；依赖缓存复制到本项目中使用，不修改 HH 工程。
- `private/`：本应用独立的签名密钥与配置。请妥善保留，勿上传到公开仓库或发给其他人。后续覆盖安装更新需要继续使用同一份签名。
- `release/`：交付的 APK 及 SHA-256 校验文件。

在 PowerShell 中运行：

```powershell
& 'E:\点餐项目\scripts\build-android.ps1'
# 同时编译设备测试
& 'E:\点餐项目\scripts\build-android.ps1' -Tests
```

构建生成的 `.build-cache/`、`.android-test/`、`android/.gradle/`、`android/build/`、`android/app/build/` 和 `android/app/src/main/assets/www/` 可以在测试结束、模拟器退出后清理；再次构建会重新生成。保留源码、脚本、交付文件和 `private/` 签名文件。

退出本项目测试模拟器后，运行 `scripts/clean-android.ps1 -Preview` 查看范围，去掉 `-Preview` 执行清理。脚本只处理已列出的生成目录。
